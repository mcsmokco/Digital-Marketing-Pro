# Digital Marketing Pro 🚀

منصة كورس Digital Marketing Pro من الصفر إلى الاحتراف.

## المزايا
- 12 وحدة تدريبية
- دروس وتمارين واختبارات
- حفظ التقدم محلياً
- دعم الحسابات والتزامن السحابي عبر Supabase
- شهادة إتمام بعد إكمال جميع الوحدات
- GitHub Pages deployment

## تفعيل الحسابات والمزامنة السحابية

1. أنشئ مشروعاً مجانياً في Supabase.
2. من **SQL Editor** شغّل محتوى `supabase-schema.sql`.
3. من **Project Settings → API** خذ `Project URL` و`anon public key`.
4. ضع القيمتين في `supabase-config.js`.
5. لا تضع `service_role` key داخل الموقع.
6. ارفع التغييرات إلى GitHub، وسيتم نشر الموقع عبر GitHub Pages.

> إذا تركت القيم فارغة، يبقى الموقع يعمل بالتخزين المحلي بدون حسابات.
